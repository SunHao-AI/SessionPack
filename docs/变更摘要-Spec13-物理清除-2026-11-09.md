## 1. 功能总览

新增本机物理清除命令 `sessionpack delete --session ID --purge --yes`：

- **库内抹除**：`messages` / `message_fts` 物理删除，`sessions` 行置 `purged` 终态并清空内容字段（`content_hash=NULL`），行保留作为 purge 卡载体。
- **三道防复活卡**：① catalog `upsert_topic` / `upsert_message` 遇 purged 行直接拒绝；② install 识别 purged 包强制落卡抹除；③ 读口径由"排除 deleted"收紧为"仅 active"，purged 对所有视图隐身。
- **归档抹除**：受影响包原位重打包（`repak`：剔除会话 ndjson、meta 置 purged、manifest 重算、自检通过后 `os.replace` 原子替换），先库后包、单包失败不中断。
- **同步目录只读报告**：`find_archives_with_session` 列出仍含该会话内容的同步副本包名，不代用户写同步目录。
- **状态机**：`active → deleted → purged`（终态，不可逆、不可降级、不可复活）。
