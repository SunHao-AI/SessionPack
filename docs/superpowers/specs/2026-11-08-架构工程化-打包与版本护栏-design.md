## 4. 设计

### 4.1 R1：pyproject 动态版本（唯一生产改动）

```toml
[project]
name = "sessionpack"
dynamic = ["version"]
description = "Trae 会话归档与同步：本地只读会话管理"
requires-python = ">=3.11"
dependencies = []
license = "MIT"
license-files = ["LICENSE"]

[tool.setuptools.dynamic]
version = {attr = "sessionpack.__version__"}
```

其余段落（`[project.scripts]`、`packages.find`、`package-data`、
`tool.pytest/ruff/mypy`）一字不动。`sessionpack/__init__.py` 保持
`__version__ = "0.3.0"` 单行——setuptools 走 AST 静态读字面量
（不实际 import 包），探针已确认解析成功。

### 4.2 R2：版本护栏（tests/test_version_guard.py，+3）

| 用例 | 断言要点 |
|------|----------|
| 版本单一来源 | `tomllib` 解析：`[project]` **不含** `version` 键、`dynamic == ["version"]`、`[tool.setuptools.dynamic].version.attr == "sessionpack.__version__"`（改回硬编码立即红） |
| 版本串形态 | `__version__` 匹配 `^\d+\.\d+\.\d+$`（三段数字，PEP 440 的合法子集），strip 后不变（防手滑带空格） |
| `--version` 一致性 | 子进程 `python -m sessionpack --version` 的 stdout == `sessionpack.__version__` 且退 0（锁 V2：用户可见版本 == 包内版本） |

### 4.3 R3：打包内容静态护栏（tests/test_packaging_contents.py，+4）

从 `pyproject.toml` 读配置，对仓库真实文件做集合断言：

| 用例 | 断言要点 |
|------|----------|
| 模块全覆盖 | `sessionpack/**/*.py`（排除 `__pycache__`）每一条都在 `packages.find.include = ["sessionpack*"]` 语义内，且其所在的每个目录都有 `__init__.py`（否则 setuptools 发现不到 → 装出来少模块） |
| web 资源随包 | `package-data` 的 glob 覆盖 `sessionpack/web/` 下**全部**文件（当前 5 个：`index.html`/`session.html`/`diagnostics.html`/`app.js`/`style.css`）；新增 web 文件无需改配置即自动纳入，删 `web/*` 条目立即红（治 P2） |
| 无越界纳入 | `tests`/`spike`/`docs`/`scripts` 四个顶层目录名均不被 include 模式匹配（防有人把 include 放宽成 `*`） |
| 入口点不悬空 | `[project.scripts].sessionpack` 的 `"sessionpack.cli:main"` 可 `importlib` 导入且目标可调用（防重构后装出来的命令直接 ImportError） |

## 5. 风险与决策

1. **冒烟默认 skip**：真构建 ~19s，进日常等于把 `check.py` 从
   ~40s 拉到 ~60s 且每次提交都付；而打包配置的**退化**几乎总是
   由 R3 的四条静态断言就能捕获（glob 删掉、include 放宽、模块漏
   `__init__.py`、入口悬空）。真构建只在发布前跑一次做端到端确认。
2. **`attr` 静态读**：setuptools 用 AST 解析 `__init__.py` 取字面量，
   不 import 包（因此不要求运行期依赖可导入）。前提是
   `__version__` 必须是**模块级字符串字面量**——R2 第 2 条正是把这个
   前提锁死（有人改成 `__version__ = get_version()` 会同时红 R2 与构建）。
3. **PEP 440 只校验三段数字**：当前工程无预发布/后置版本需求，
   用严格子集 `^\d+\.\d+\.\d+$`；真需要 `0.4.0rc1` 时再放宽（届时
   R2 一条测试的改动作决策，不预支灵活性）。
4. **不改 editable 安装态**：`.venv` 里 `-e` 装的 dist-info 仍写着
   旧来源，但运行期读的是源码，测试全部走 `tomllib` + 真实子进程，
   不依赖已安装元数据，故无需重装（探针亦在隔离副本、非 editable）。
5. **不建 CHANGELOG**：无发布流水与对外沟通需求，主动新增文档文件
   属过度工程（构想稿 §发布 的 changlog 一条就此明确放弃，记为决定）。
