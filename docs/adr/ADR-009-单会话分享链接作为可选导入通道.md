# ADR-009 单会话分享链接作为可选导入通道

- 状态：已采纳
- 日期：2026-11-10
- 决策范围：Trae 官方单会话分享链接（`share.traecontent.cn`）是否纳入导入通道、以何种形态纳入
- 相关文档：[ADR-008](ADR-008-内置数据库逆向与冷热分离作为未来方向.md)（补充路线一节）、[项目构想](../../项目构想-Trae会话归档与同步.md) 20.2 / 20.5 / 20.6、原型 `spike/trae_share_export.py`

## 背景

ADR-006/008 确立的口径是：分享链接把内容上传官方云端，与「数据不出本机」原则相悖，**不纳入导入通道**。B1 验证（2026-11-10）进一步确认：官方 Markdown 导出会丢弃图片，而分享链接页面**含图片**（签名 CDN 动态加载）与工具摘要行，是记忆目录和官方导出之外的第三种内容形态。

用户提出：单会话分享链接建议支持，由用户根据需要进行选择。这把问题从"要不要通道"变为"通道以什么形态存在才不违背原则"。

## 决策

1. **分享链接成为 opt-in 可选导入通道**：新增 `sessionpack fetch-share <链接...>` 子命令，用户主动逐链接发起抓取；默认导入路径（`import` / `scan` / `sync`）不受任何影响。
2. **playwright 惰性导入，守零第三方运行时依赖红线**：核心包不声明依赖；`fetch-share` 运行时才 `import playwright`，缺失时以一行错误提示 `pip install playwright && playwright install chromium`。全量测试环境无 playwright 也不失败。
3. **图片一并入库**（用户明确选择，否决"仅落盘不入库"）：
   - 唯一存储口径 `<data-dir>/images/<session_id>/<file>`；
   - 抓取期在浏览器内为每张图采集"所在消息文本前 120 字符"片段写入 `manifest.json`，解析期归一化（折叠空白）取前 40 字符做包含匹配，挂到对应消息的 `meta_json.images`（免改 schema），匹配不到兜底挂最后一条；
   - 归档包新增成员 `sessions/<id>/images/<file>` 并登记进 manifest（verify 天然校验、`archive_id` 含图片哈希、改图即改 ID）；`import_archive` 增 `images_dir` 参数解包落位；加密在整包 zip 层，零改动；
   - Web 详情页经受 token 保护的 `/api/images/` 路由渲染，路径解析带多重防穿越校验（正则 + resolve + is_relative_to）。
4. **session_id 口径不变**：仍为 `_sha24(project_id + title + 全部消息)` 内容哈希，图片只进 `meta_json` 不进正文，幂等与去重语义不受影响。

## 备选方案

| 方案 | 未采纳原因 |
|---|---|
| 维持"不纳入"（原口径） | 用户明确需要；含图片对话是记忆目录与官方导出都覆盖不了的缺口 |
| 图片仅落盘、不入库不进归档 | 用户否决：脱离归档/Web 的图片在换机与重建后失联，等于半丢数据 |
| playwright 列为硬依赖 | 破坏零第三方运行时依赖红线，污染所有用户的安装 |
| 独立伴生工具（spike 形态维持） | spike 无 CLI 集成、无图片关联、无归档/Web 链路；用户要在正式 CLI 内按需选择 |

## 后果

正面：

- 含图片的单会话可完整归档、检索、随包同步、Web 可视，且只在用户主动选择时才触碰云端。
- 默认通道行为零变化；`archive_id` 对图片内容的覆盖使归档防篡改语义更完整。

代价与接受理由：

- "数据不出本机"从绝对原则软化为"默认不出本机、可选通道用户自担"——由 opt-in 与文档口径（构想稿 20.2/20.5/20.6 同步改为"默认不纳入、用户按需选择"）承担。
- 抓取依赖 Trae 分享页 DOM（虚拟列表、CDN 签名），随官方改版可能失效；失效表现为抓取失败退出码非 0，不损坏既有数据。
- 图片匹配基于文本片段包含，极少数同文重复消息可能挂错位置；兜底策略保证不丢图。

## 后续修订指针

- Trae 官方若提供含图片的完整导出格式，应优先官方通道并重新评估本通道去留。
- 分享页结构变化导致抓取失败率上升时，更新 `fetchshare.py` 的选择器；必要时在 doctor 中加分享页连通性探测。
